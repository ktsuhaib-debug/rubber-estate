# Rubber Estate

Family app for tracking the two rubber estates: daily tapping, estate work, sheet sales, tapper wages, and PDF statements.

- **Root folder** – the full-screen launcher served by GitHub Pages (icon, manifest, and a page that loads the app).
- **`app/`** – a backup copy of the Apps Script code (`Code.gs`, `Index.html`). The live app runs from the Apps Script project attached to the Google Sheet; to update it, paste these files into the Apps Script editor and deploy a new version.
